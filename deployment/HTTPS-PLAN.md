# Подключение vse-vozmozhno.ru: подготовленный план

Статус: НЕ ПРИМЕНЕНО. 07.11.2026: в кабинете домен ACTIVE, телефон подтверждён, NS корректны; авторитетная зона .ru пока возвращает NXDOMAIN. A-запись Selectel правильная.

Общий вход 80/443 обслуживает контейнер skazka-recovery-https-1. Запрет пользователя менять существующие проекты требует согласования узкого исключения.

Конкретное дополнение: два новых server-блока из nginx-domain.conf.draft внутри http{} файла /srv/skazka/deployment/nginx.conf. Они обрабатывают только vse-vozmozhno.ru. Существующие server-блоки остаются без изменений.

Отдельный шлюз business-card-edge принадлежит проекту визитки, связывает только HTTP приложения с общей front-сетью, БД в общую сеть не подключается. До применения создать и проверить его; конфигурация шлюза пока не развёрнута.

Сертификат и ACME-состояние хранить в /srv/backend-business-card/certificates. Для доступа существующего nginx только два файла сертификата нового домена публикуются в новой подпапке /srv/skazka/certificates/letsencrypt/business-card/ (ключ0600). Существующие сертификаты не менять. HTTP-01 использует отдельные случайные challenge-файлы в уже смонтированном acme-webroot. Автопродление должно проверять сертификат, заменять только файлы визитки, проверять nginx -t и выполнять graceful reload.

Порядок после разрешения и публикации DNS:
1. Снять текущую конфигурацию/хеш и baseline доступности сказок/CRM; подготовить rollback. Не перезаписывать параллельные изменения другого чата.
2. Проверить отдельный шлюз; добавить только HTTP challenge нового домена; nginx -t, graceful reload.
3. Выпустить сертификат для одного домена; установить два файла в отдельную подпапку.
4. Добавить HTTPS-блок/редирект; nginx -t, graceful reload без остановки контейнера.
5. Проверить доверенный TLS, редирект, GraphQL с данными Алексея, Sandbox, неизменность поведения сказок/CRM.
6. Установить и проверить автопродление только сертификата визитки. Обновить README и ссылку GitHub после успешной проверки.

Это план и проверяемый фрагмент, не свидетельство работающего HTTPS. Платных ресурсов не создавали, чужие файлы не меняли.
