# Развёртывание и изоляция

Новый репозиторий и новый Compose-проект: `backend-business-card`. Отдельная тестовая среда: `backend-business-card-tests`.

На согласованном сервере используется только каталог `/srv/backend-business-card`. Тестовая БД — порт127.0.0.1:55439, приложение —127.0.0.1:4310. Основная БД не публикует порт. Существующие приложения и их файлы/БД/контейнеры не изменять.

Пароль хранится в исключённом из Git `.env`. При переносе не включать в архив .env, .git, память родительского проекта и сторонние материалы. Локальный пример не является production-секретом.

Для просмотра с рабочего компьютера можно открыть SSH-туннель:

```sh
ssh -N -L 4310:127.0.0.1:4310 <ваш-SSH-сервер>
```

Затем открыть http://localhost:4310/graphql. Это закрытая проверка, не ссылка для работодателя.

Перед публичной публикацией выбрать домен/поддомен, HTTPS и отдельный GitHub-репозиторий. Изменение существующего общего HTTPS-сервиса не входит в уже выполненную изолированную установку: сначала согласовать конкретную запись/маршрут. Не менять DNS почты или действующих приложений.

Ограничения основного Compose: приложение768МБ/0.5CPU, БД512МБ/0.5CPU. ТестоваяБД512МБ/0.5CPU. Останавливать тестовую среду после проверок, сохраняя данные при необходимости. Эти лимиты не резервируют ресурсы и не ограничивают расход диска; контролировать размер volume/образов. Предварительный запас5–10ГБ диска,1–2ГБRAM относится к небольшой демонстрации, не нагрузочному SLA.

Перед удалением убедиться, что текущий каталог именно этот проект, и имя Compose соответствует ему. Сначала сохранить необходимые данные. Удалять только ресурсы конкретного проекта. Никогда не очищать весь Docker на общем сервере.
